# Rival aim strength and difficulty

## BL-75 — Choose `couples.rival_aim` by how hard the game is for an engaged player, not only the passive cut
- **Open:** Terrace sets `social_tracks.couples.rival_aim` to 0.3 (each resident of the player's gender starts with one crush; the number is how strongly it counts). Owner goal (2026-09-30): the game should be hard. Over 12 seeded houses the passive-player director cut came on days 95-136 without aims and 95-173 with them, so aims made the passive game easier in the tail (the director cuts you after three other couples leave; slower couples = more time). Unmeasured: how aims change difficulty for a player who is trying, because a rival can take the person the player is winning. Cause of the slowdown is a guess (fixed crushes steer attention away from natural pairings), not verified.
- **Next:** an offline sweep, no model calls (about 40 minutes): 12 seeded houses at `rival_aim` 0, 0.15 and 0.3, for both player genders, using the seeded strategic campaign (`test_terrace_campaigns.py` pattern). Record per house and setting: days to the win (or no win by 60 days), whether a rival coupled with the player's target first, whether the player was cut, and the passive cut day. Pick the value that makes the engaged game harder without slowing the passive cut; if none does, keep the aims for visibility and add pressure elsewhere (how fast other couples form). Put the table in `design/SOCIAL_ENGINE.md` and set the story value.
