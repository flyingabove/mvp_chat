How to create a new character:

1.) Need new character JSON here: backend\app\knowledge\characters\
- The folder name is the ID. For example "1_iu". 1 is the number and iu is the name of the character and game. For example, if the game was going to be "jennie murder mystery", we could give the ID: "2_jennie". If it is unclear who the example character is, ask. Instructions should give you someone specific such as "Jennie Kim from Blackpink".
- Then, in the JSON knowledge.json, copy the format from backend\app\knowledge\characters\1_iu\knowledge.json. Search the internet for relevant facts about this person. If this person is not real or is ambiguous, call it out and ask. Do not ever hallucinate anything, always ask. (backend\app\knowledge\characters\1_iu\knowledge.json)
- Then, using the knowledge.json, create chunks.jsonl, which is fed into FAISS for retrieval. Study how backend\app\knowledge\characters\1_iu\chunks.jsonl is created from backend\app\knowledge\characters\1_iu\knowledge.json and generate a similar JSON of at least the same size or larger in the new folder with the new knowledge.json and chunks.jsonl for the new character.

2.) Need new story here: backend\app\stories\
- Generate a new story json using this as example: backend\app\stories\1_iu\iu_murder_mystery.json For folder creation use same convention such as 1_iu or 2_jennie, samne as character creation instructions
- Make sure the json length is at least as many lines as the stories example if not more
- Generate a robust world for it. Example: backend\app\stories\1_iu\iu_murder_mystery_world.json
- Make sure the json length is at least as many lines as the world example if not more
- Generate an isometrics map for the game using backend\app\stories\1_iu\iu_murder_mystery_wm.png as an example and in approximately the same art style.
- Make sure the image makes sense and is robust. e.g. no random sidewalks going off a cliff or parking lot miles away from apartment.

3.) Make sure the game is integrated into the index.html main menu somehow and user can select it

4.) Write a robust integration test to make sure all the data loads correctly. Make sure that when game starts, all data actually loads

5.) Run all unit and integration tests and make sure they all pass.
